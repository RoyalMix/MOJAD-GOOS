# MOJAD GAME-TO-OPPORTUNITY PROTOCOL

PLAY
↓
LEARN
↓
BUILD
↓
COMPETE
↓
CONNECT
↓
SKILL
↓
IDENTITY
↓
TRUST
↓
OPPORTUNITY
↓
ECONOMIC PARTICIPATION

Game activity may produce supplementary skill signals.

Game scores alone must never be treated as proof of professional competence.

Signals should include context such as:

- task type
- difficulty
- consistency
- collaboration
- problem solving
- creativity
- decision making
- learning progression
- verified achievements

Signals must be explainable and privacy-aware.

The system must never automatically make high-impact employment, education, financial or eligibility decisions solely from game-derived signals.
