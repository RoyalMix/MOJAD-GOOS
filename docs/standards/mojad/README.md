# MOJAD GOOS — Manual Upload Pack

Repository-ready proposed standards and implementation plans. These files do **not** prove features are implemented, production is secure, or a payment rail is enabled.

## Upload
1. Download and extract this ZIP.
2. Open `RoyalMix/MOJAD-GOOS` on GitHub.
3. Compare with existing canonical docs first; upload under the repository's established documentation path (suggested: `docs/standards/mojad/`).
4. Do not overwrite authoritative files without reviewing the diff.
5. Commit only after review, e.g. `docs: add MOJAD economy and implementation standards`.
6. Use `10_TOOL_EXECUTION_PROMPTS.md` when delegating work to Bolt, Pi AI App Studio, Replit, Lovable, or Copilot.

## Core rule
**Audit → Verify → Reuse → Design → Implement → Test → Security → Evidence → Human Review → Release → Monitor → Evolve.**
One approved vertical slice at a time; never rebuild existing working core services.
