# MOJAD SOURCE, EVIDENCE & VERIFICATION STANDARD™ v1.0

Status: DESIGN / FOUNDATION

## Core principle
MOJAD DATA ≠ TOOL ACCESS.

A tool may access data without owning it.

## Data classes
### Crown Jewel
Identity, private conversations, private AI memory, payments, Pi evidence, trust/reputation evidence, security logs, proprietary opportunity intelligence, fraud/security signals and secrets.

### Controlled/Public MOJAD data
Public opportunities, jobs, businesses, courses, events, creator content and public market/research information.

### External/public intelligence
Government, research, public blockchain, public company data and official announcements.

## Zero Trust Tool Architecture
Tool → identity → permission → classification → policy → audit → allow/deny.

## Access Gateway
Every sensitive tool/data request should be evaluated for identity, purpose, permission, data scope, environment and auditability.

## Source hierarchy
1. Primary official
2. High-quality secondary
3. Community
4. Unverified
5. Unknown

## Evidence Engine
Claim → Source → Authority → Date → Evidence → Confidence → Conflicts → Freshness → Status.

## Statuses
VERIFIED, LIKELY, REPORTED, CONFLICTING, OUTDATED, UNKNOWN.

## Intelligence network
World Scanner, Opportunity Scout, Threat Intelligence and Competitive Intelligence agents operate only within legal, authorized data boundaries.

## Early Warning
Collect → Verify → Classify → Correlate → Detect Change → Risk/Opportunity → Warning → Authorized Action.

## Security
Detect early, verify independently, minimize access, isolate damage, preserve evidence, recover and learn. No retaliation or unauthorized hacking.

## Agent security
Agent ID, owner, purpose, permissions, tools, data scope, environment, risk level, limits, audit log and kill switch.

## Pi rule
Pi-native does not mean Pi-dependent. Market signals, exchange prices and community claims must not be confused with official protocol truth.

## Non-negotiables
No source is truth merely because it is available.
No AI claim is fact merely because AI generated it.
No market signal is protocol truth merely because it has a price.
No intelligence becomes action without authorization.
