# MOJAD COMPUTE, CLOUD, EDGE & DISTRIBUTED INTELLIGENCE ARCHITECTURE™ v1.0

Status: DESIGN / FOUNDATION

## Purpose
Provide provider-neutral compute infrastructure for MOJAD Intelligence Swarm and products.

## Compute Fabric
Cloud + GPU + CPU + Edge + Local + Distributed Compute.

## Cloud
APIs, auth, databases, AI orchestration, search, Knowledge Graph, Opportunity Engine, messaging, notifications, analytics, storage, queues and monitoring.

## GPU
LLM inference, vision, speech, video, embeddings, simulations and heavy analytics.

## CPU
APIs, business logic, databases, queues, ETL, validation, events and security checks.

## Compute Router
Select compute by workload, latency, privacy, budget, availability, workload size, geography and compliance.

## Edge
Phones, desktop, Pi Desktop, permitted Pi Nodes/SoloHost, business servers, local gateways and IoT devices.

Pi Node/SoloHost compute must not be assumed as a production capability until directly verified.

## Distributed compute
Every participating node needs identity, ownership, capacity, security status, workload permissions and auditability.

## Workload classes
A Public, B Internal, C Private, D Highly Sensitive, E Critical.

## Scheduler
Priorities: realtime, urgent, normal, batch, background, research.
Consider cost, latency, security, redundancy and resource availability.

## Model serving
Intent + complexity + privacy + latency + cost → model selection. Support fallback without weakening evidence/security standards.

## Storage
Hot, warm, cold, knowledge, evidence, media and recovery storage through provider-neutral adapters.

## Agent sandbox
Agent → sandbox → policy → tool → result. No production shell by default.

## Compute observability
CPU/GPU, memory, storage, bandwidth, latency, queue, failures, cost, energy and utilization.

## Disaster recovery
Primary, replica, backup and recovery region with defined RPO/RTO and tested restoration.

## Security
Authenticated, authorized, isolated, monitored, rate-limited and audited. Untrusted code runs in sandboxed environments.

## Principle
One Compute Fabric, many products. Do not create duplicate AI/queue/storage/monitoring infrastructure.
