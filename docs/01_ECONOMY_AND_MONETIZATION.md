# MOJAD PRODUCT PLATFORM CONSTITUTION™ v1.0

Status: DESIGN / FOUNDATION
Canonical authority: GitHub
Implementation status: No production mutation authorized by this document alone.

## 1. Purpose
MOJAD GOOS is a Global Opportunity Operating System focused on Opportunity Intelligence & Economy Orchestration Layer™.

## 2. Core principles
- ONE MOJAD. ONE PRODUCT PLATFORM. ONE SOURCE OF TRUTH. MANY PRODUCTS. MANY EXPERIENCES.
- GitHub is the canonical source of truth for code, contracts, architecture, migrations, tests, CI/CD, governance and important documentation.
- ChatGPT is a strategy/research/architecture workspace; builders are workers, not authorities.
- Preserve existing working systems before adding or replacing anything.
- Audit before implementation.
- Reuse before rebuild.
- No duplicate authoritative systems.
- No fake production data, fake Pi balances, fake transactions or fake provider status.
- Pi-native where useful, but Pi-independent.
- Provider-neutral adapters are mandatory for strategic external dependencies.
- Sensitive actions require authorization and appropriate human approval.
- Production changes require evidence, tests, rollback and approval.

## 3. Lifecycle
BUILD → CONNECT → TEST → VERIFY → APPROVE → PUBLISH → MONITOR → IMPROVE.

## 4. Evidence statuses
VERIFIED-CODE, VERIFIED-DATABASE, VERIFIED-PROVIDER, VERIFIED-RUNTIME, BASELINE-REPORTED, PARTIAL, UNKNOWN, BLOCKED.

Absence in GitHub does not prove absence in production. A reported capability is not a verified capability.

## 5. Tool governance
ChatGPT, Copilot, Lovable, Replit, Pi tools and other builders may propose or implement changes only within approved contracts and governance. No tool may redefine MOJAD architecture unilaterally.

## 6. Human control
Humans retain final authority for architecture, security, money, identity, legal/compliance, production deployment and destructive actions.

## 7. Definition of Done
A production product/capability needs an owner, contract, implementation, integration, data/security controls, tests, evidence, observability, rollback and human approval.
