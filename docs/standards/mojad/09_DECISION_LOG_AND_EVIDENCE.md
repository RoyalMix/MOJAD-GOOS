# MOJAD GOOS Decision Log & Evidence Register

## Decision template
ID; date/timezone; status (`PROPOSED`/`APPROVED`/`REJECTED`/`SUPERSEDED`); owner; context; options; decision/rationale; affected services; security/privacy/compliance impact; cost/operations; evidence/sources; tests; rollback; review date.

## Evidence template
Evidence ID; capability; status vocabulary; repo/commit SHA; file paths/symbols/migration IDs; test command/environment/result; runtime/provider evidence; limitations; reviewer; date/timezone.

## Proposed decisions (not yet approved)
1. MOJAD Credits are internal usage units, not Pi or a blockchain token.
2. Pi is a preferred native rail where official integration and current terms support the use case.
3. Stablecoins/fiat require individual provider, jurisdiction and compatibility review.
4. Costly AI/media tasks use quote, consent, idempotent reservation, usage settlement and fair failure handling.
5. Rewards require funding source, budget, fraud controls and finance approval.
6. AI tools use server-side permissions and cannot grant themselves authority.
7. Existing services are audited/reused before replacements are proposed.
8. Production payment, identity, security and migration changes require human approval.
