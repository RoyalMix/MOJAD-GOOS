# MOJAD DATA & KNOWLEDGE ARCHITECTURE STANDARD™ v1.0

Status: DESIGN / FOUNDATION

## Master flow
DATA → KNOWLEDGE → INTELLIGENCE → OPPORTUNITY → ACTION → OUTCOME → LEARNING.

## Canonical entities
Person, Organization, Business, Job, Skill, Course, Investor, Startup, Product, Service, Property, Grant, Scholarship, Government Program, Community, Event, Creator, Content, Game, Payment, Pi Transaction, Country, City, Industry, Technology, Scientific Concept and Research.

## Entity resolution
Use identifiers, names, domains, location, relationships and provenance. Never merge entities solely because names look similar.

## Provenance
Important derived information must trace back to source, timestamp, transformation and evidence.

## Knowledge Graph
Entities + relationships. Search finds; the Knowledge Graph contextualizes; AI reasons; Opportunity Engine turns intelligence into action.

## Opportunity DNA
opportunity_id, type, source, organization, location, industry, skills, education, experience, capital, deadline, urgency, availability, trust, requirements, benefits, economic_value, status and freshness.

## Search flow
Query → intent → entity recognition → semantic search → Knowledge Graph → filters → freshness → trust → ranking → explanation.

## AI memory
Session, conversation, user, product, knowledge, opportunity and system layers with user-scoped permissions.

## Recommendation signals
Profile, intent, skills, location, trust, history, knowledge, freshness and Opportunity DNA.

## Intelligence domains
Technology, Science, Economic, Weather/Environment, Business, Government, Crypto/Pi and Opportunity.

## Source Registry
source_id, name, type, authority, API/access method, license, terms, geography, language, update frequency, reliability, last verified and status.

## Conflict statuses
VERIFIED, LIKELY, REPORTED, CONFLICTING, OUTDATED, UNKNOWN.

## Freshness
Measure source update time, ingestion latency, validation time, index time and recommendation refresh time.

## Schema discipline
Inspect production schema before migration. Do not change production from assumptions.

## Principle
MOJAD should build a measurable Opportunity World Model, not claim to possess a complete model of the world.
